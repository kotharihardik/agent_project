**One-line story so far:** pressure sensors alone can rarely point to a street. Citizen reports plus pressure, fused honestly, beat every baseline but still can't justify digging from one look. Cheap, well-chosen checks (listening, asking, step tests), picked by their value for the dig decision, find leaks with far fewer wrong digs. In Phase 3 an LLM investigator works on a safe, code-checked toolbox: it is never tricked into unsafe digs (a standard ReAct agent dug at an attacker's spot 4 times in 102 test cases) and it is the most careful investigator (0 % false dispatch, fewest wrong digs), but it finds fewer leaks than simple rules. Making it find more without losing that care is the Phase 4 target.
